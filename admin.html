Shipping rates

Cart estimates parcel weight from product size using 3 mm Corten plate density × silhouette fill + packaging, then picks a price tier. Save publishes live for the cart and Stripe.

General

Rural delivery

Cart auto-detects rural from the address (with an override tick). Rural addresses cost more by this surcharge on top of the weight tier.

Corten plate weight

Used for sculptures, signage and house numbers (bounding box × fill). Solid 3 mm Corten is about 23.55 kg/m²; fill is how much of the box is steel (cut-outs lower it).

House number formula (floor)

Cart uses the heavier of silhouette estimate vs this formula, so rates stay safe. Formula: chars × (base + height_mm × per_mm) + holes extra.

One-time setup (no KV)

Products are saved into your GitHub repo. You only need two secrets on the page you already have open:

  1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token
    Enable scope repo → Generate → copy the token
  2. Cloudflare → corten-living → Settings → Variables and secrets → + Add (Production):
    • Secret ADMIN_PASSWORD = e.g. CortenAdmin!
    • Secret GITHUB_TOKEN = the token you copied
  3. Deployments → latest → Retry deployment
  4. Reload /admin — badge should say Cloud live
